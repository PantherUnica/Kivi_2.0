# Product Vision Document (590 words)

**What semantic memory should let Kivi become**

Kivi already earns trust at the word level — Styles shape how speech becomes writing, phonetic memory learns which words are the user's own. Semantic memory is the layer above the word: the record of what was said and decided, and the patterns in how it was said. Our own 100-response survey shows why this matters more than generic personalization — 96% have already been surprised by an AI remembering something across chats, so the expectation is set; yet only 20% are "very comfortable" with that memory today, and professionals are more guarded still (13%). The opening isn't for Kivi to know more, it's to know a narrow set of things well enough to close that trust gap — becoming the assistant that already has your record, not one that has profiled you.

**Where the value is created**

Value sits in moments ranked directly by the people we surveyed, and the ranking shifts by who's answering. Every segment agrees on the top one: producing text that already sounds like the person — working style & tone is the single highest-ranked work memory for both students (81%) and professionals (87%). Below that, priorities diverge in a way the build order should respect. Students rank deadlines & commitments their *least* useful work memory (59%); professionals rank it their *second-highest* (80%, nearly tying style itself) — real external stakes make recall of commitments, not just tone, the second pillar of value for a working audience. Cowan's work on limited working-memory capacity (2001) explains why offloading either, instead of re-stating it every session, is the real relief.

**What deserves to be remembered**

Two categories: episodes (what happened, when) and communication patterns (how this person writes for a client versus a teammate). Both are read off the transcript, never interpreted from it. People & relationships is the one memory type both segments independently reject — last place for students (24% top-2) and, even among professionals who are otherwise more open to remembering personal categories, still last (33%). Grounding, per Clark & Brennan (1991), is what lets two parties skip re-establishing shared context each time; Kivi's memory should build exactly that, and nothing more.

**What Kivi must never assume**

Kivi must never convert an inference into a stored fact, and must never build a model of who someone is. Professionals set the harder line here and the product should default to it: 87% want relationship conflicts excluded from automatic memory (vs. 65% of students), 67% want financial situation excluded (vs. 40%), and professionals are twice as likely to refuse sensitive work topics outright (33% vs. 14%). Building to the stricter threshold is safe for everyone; building to the softer aggregate is not. Culnan & Armstrong's privacy-calculus research (1999) explains the mechanism: explicit disclosure reads as a fair exchange, inference reads as surveillance.

**Why someone should trust it enough to keep using it**

Trust isn't earned by omniscience — Lee & See (2004) call this appropriate reliance, not maximum trust. It also isn't earned in the same order for everyone: students want to *delete* what's stored above all else (79%), professionals want to *see* it first (87%, their single highest trust ask of any kind). That ordering should decide what ships first — a legible "what Kivi knows" view before, or alongside, one-tap delete, not after it. Per Deci & Ryan's autonomy research (2000), the control itself has to be one sentence away regardless of which comes first. Kivi keeps that promise: every memory traces to its source, corrects on request, and is offered back as a question — never a claim — the moment it's uncertain.
